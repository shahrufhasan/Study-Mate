## 🌟 Overview
**Study‑Mate** is a web application designed to help students organize their study schedules, track their progress, and collaborate with peers.  
It is a simple, responsive, and user-friendly platform for managing study tasks efficiently.

---

## 🛠️ Main Technologies Used
- **Frontend:** React, JavaScript, HTML5, CSS3  
- **Backend:** Node.js, Express  
- **Database:** MongoDB  
- **Hosting / Deployment:** Netlify (frontend) / *(Add backend hosting if applicable)*  

---

## ⚡ Main Features
- 📚 Add, edit, and delete study tasks  
- ✅ Mark tasks as complete to track progress  
- 🗓️ Organize tasks by date or subject  
- 👥 Collaborative mode for working with friends  
- 🔍 Fully responsive design for desktop and mobile  

---

## 📦 Dependencies Used
- `react` – Frontend framework  
- `react-dom` – React DOM rendering  
- `react-router-dom` – Page routing  
- `axios` – API calls  
- `express` – Backend framework  
- `mongoose` – MongoDB object modeling  
- `cors` – Cross-Origin Resource Sharing  
- `dotenv` – Environment variable management
