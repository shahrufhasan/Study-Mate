## 📖 Project Overview

**Study-Mate** is a web application designed to help students organize their study schedules, track their progress, and collaborate with peers. Users can search for study partners based on their interests, subjects, and preferences, making it easier to find compatible study buddies.

## ✨ Core Features

- 🔍 **Search Study Partners** - Find study partners based on your interests, subjects, and preferences
- 📚 **Task Management** - Add, edit, and delete study tasks to stay organized
- ✅ **Progress Tracking** - Mark tasks as complete to track your study progress
- 🗓️ **Organize by Date/Subject** - Sort and filter tasks by date or subject
- 👥 **Collaborative Mode** - Work together with friends on shared study goals
- 🔐 **User Authentication** - Secure login and registration system
- 📱 **Fully Responsive** - Works seamlessly on desktop, tablet, and mobile devices

## 🚀 How to Run Locally

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn
- MongoDB Atlas account or local MongoDB installation

### Step 1: Clone the Repository
```bash
git clone https://github.com/shahrufhasan/Study-Mate.git
cd Study-Mate
```

### Step 2: Install Dependencies
```bash
npm install
```

### Step 3: Set Up Environment Variables
Create a `.env.local` file in the root directory:
```env
VITE_API_URL=your_backend_api_url
VITE_FIREBASE_API_KEY=your_firebase_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_firebase_auth_domain
VITE_FIREBASE_PROJECT_ID=your_firebase_project_id
```

### Step 4: Run the Development Server
```bash
npm run dev
```

### Step 5: Open in Browser
```
http://localhost:5173
```
